    Seller Exchange — AS Feature Stories v3¶

    Version: 3.0
    Status: Draft
    Purpose: Content strategy for short product videos (15–30 sec)

    Vision¶

    AS Feature Stories — это библиотека коротких продуктовых историй, каждая из которых показывает решение одной реальной бизнес-задачи.

    Это не реклама.

    Это не обучение.

    Это не обзор интерфейса.

    Это короткие истории о том, как Seller Exchange помогает Amazon Seller решить конкретную задачу быстрее, проще и понятнее.

    Каждая история отвечает только на один вопрос пользователя.

    "Как решить эту задачу за несколько кликов?"

    Design Principles¶

    Every story should be:

    • One business problem
    • One feature
    • One workflow
    • One result

    После просмотра пользователь должен подумать:

    "Хочу попробовать это."

    Если история требует более 30 секунд, значит это уже Tutorial, а не Feature Story.

    Motion Language¶

    Настроение роликов должно быть похоже на Telegram Feature Updates, а не на кинематографичные продуктовые презентации.

    Используется:

    • Реальный интерфейс платформы
    • Настоящий курсор
    • Hover
    • Click
    • Typing
    • Loading
    • Progress
    • Table Refresh
    • Numbers Updating
    • Charts Animation
    • Toast Notifications
    • Small Zoom (105–110%)
    • Small Emoji Accents
    • Short Captions (до 5 слов)

    Не используется:

    • 3D Camera
    • Fake UI
    • CGI
    • Long Titles
    • Heavy Motion
    • Cinematic Effects
    • Excessive Transitions

    Each Story should produce:

    • Marketing Brief
    • Script
    • Storyboard
    • Motion Specification
    • Screen Recording Checklist
    • Editing Checklist
    • Thumbnail
    • Caption
    • Telegram Version
    • LinkedIn Version
    • Website Version

    Success Metric¶

    Каждая Feature Story должна быть понятна без озвучки.

    Через 20–30 секунд пользователь должен понимать:

    • какую проблему решает эта функция;
    • как она работает;
    • какую пользу она приносит;
    • почему стоит попробовать Seller Exchange.

    Если это достигнуто — история выполнена успешно.
