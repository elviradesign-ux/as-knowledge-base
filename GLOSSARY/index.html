    Glossary — единый словарь терминов¶

    Единственный источник определений Seller Exchange (внутр. AmazonService / AS). Термины из статей ссылаются сюда (см. STYLE_GUIDE). Правило: один термин — одна запись.

    Первоисточники: Obsidian Vault/wiki/*, platform-routes.md.

    Формат записи¶

    ### Термин
- **EN:** … · **UA:** … · **ZH:** …
- Определение: одно-два предложения.
- См. также: [[связанный-термин]], экран/сценарий.

    Платформа и сущности¶

    Seller Exchange / AmazonService (AS)¶

    • EN: Seller Exchange · UA: Seller Exchange · ZH: Seller Exchange
    • Мульти-ролевая SaaS-платформа для продавцов Amazon: заменяет 5–10 отдельных инструментов (Helium10, JungleScout, Keepa, SellerApp и др.) единым рабочим пространством — товары, заказы, инвентарь, склады, аналитика, командная работа.
    • Внутреннее кодовое имя — AmazonService / AS.

    Карточка продукта (Product Card / ASIN card)¶

    • EN: Product card · UA: Картка товару · ZH: 商品卡片
    • Единица товара с данными ASIN, вариантами и статусом готовности. Проходит пайплайн ресёрч → проверка → публикация на бирже.
    • См. также: [[ASIN]], [[Биржа товаров]], [[Готовые к проверке]].

    ASIN¶

    • EN: ASIN · UA: ASIN · ZH: ASIN
    • Amazon Standard Identification Number — идентификатор товара на Amazon. Проверяется через ASIN-чекер (Supervisor Settings).

    Заказ (Order)¶

    • EN: Order · UA: Замовлення · ZH: 订单
    • Запрос клиента на закупку товара; проходит жизненный цикл от Pending до Order complete. Обрабатывается Buyer, комплектуется Storekeeper.
    • См. также: [[Статус заказа]], [[Коробка]], [[Партия]].

    Статус заказа (Order status)¶

    • EN: Order status · UA: Статус замовлення · ZH: 订单状态
    • Этап жизненного цикла заказа. Канонические коды (FORMED=0 … SHIPPED=50) — в ENTITY_STATES → «Статусы заказа». Вкладки Buyer: not-paid, ready-for-payment, partially-paid, need-track-number, inbound, confirmation-required, closed-and-canceled.
    • См. также: [[Заказ]], ENTITY_STATES, WORKFLOW_CATALOG.

    Коробка (Box)¶

    • EN: Box · UA: Коробка · ZH: 箱
    • Физическая единица хранения/отправки товара на складе. Коробки создаются, редактируются, группируются, объединяются, перераспределяются и перемещаются в партии.
    • См. также: [[Партия]], [[Склад]].

    Партия (Batch)¶

    • EN: Batch · UA: Партія · ZH: 批次
    • Группа коробок, отправляемых вместе. Статусы: ожидающие отправки, отправленные, архив. Имеет Prep ID.
    • См. также: [[Коробка]], [[Склад]].

    Тариф (Tariff)¶

    • EN: Tariff · UA: Тариф · ZH: 资费
    • Стоимость логистики/хранения по региону. Настраивается в Управлении складом (WarehouseManagementView), уточняется модалками TariffModal, LogisticsTariffModal.

    Поставщик (Supplier)¶

    • EN: Supplier · UA: Постачальник · ZH: 供应商
    • Источник товара. Находится Buyer, верифицируется Supervisor. Данные: цена, доставка, HS-код, материал, назначение.
    • См. также: [[Заказ]], [[Карточка продукта]].

    Идея / Запуск товара (Idea / Product Launch)¶

    • EN: Idea / Product launch · UA: Ідея / Запуск товару · ZH: 选品/上新
    • Кандидат на запуск: проходит вкладки new-ideas → on-checking → supplier-search → create-card → adding-asin → realized/rejected. Управляется через IdeaModal.

    Ниша (Niche)¶

    • EN: Niche · UA: Ніша · ZH: 细分市场
    • Раздел биржи товаров с нишевыми предложениями (NicheView).

    Магазин (Store / Shop)¶

    • EN: Store · UA: Магазин · ZH: 店铺
    • Подключённый аккаунт Amazon с авто-обновлением данных. Раздел /shops.

    Роли и доступ¶

    Роль (Role)¶

    • EN: Role · UA: Роль · ZH: 角色
    • Набор прав RBAC. 8 продуктовых ролей + служебные (Moderator, Guest).
    • См. также: PERMISSIONS_MATRIX.

    Саб-пользователь (Sub-user)¶

    • EN: Sub-user · UA: Суб-користувач · ZH: 子用户
    • Дополнительный пользователь под основным аккаунтом с урезанными правами (SubUsersView, LinkSubUserModal).

    Пресет разрешений (Permissions preset)¶

    • EN: Permissions preset · UA: Пресет прав · ZH: 权限预设
    • Именованный набор доступов, уточняющий права внутри роли. Настраивается через PermissionsModal, SinglePermissionModal, GroupPermissionModal.
    • См. также: [[Роль]], [[Саб-пользователь]].

    Роли (короткие определения)¶

    • Admin (Админ) — полный доступ, настройки, права, парсинг.
    • Supervisor (Супервайзер) — проверка карточек, верификация поставщиков, ASIN-чекер.
    • Buyer (Байер) — сорсинг, поставщики, обработка заказов.
    • Client (Клиент) — конечный клиент: заказы, инвентарь, склад, аналитика.
    • Researcher (Ресечер) — ресёрч, создание карточек.
    • Storekeeper (Сторкипер) — склад, коробки, партии, задачи.
    • Freelancer (Фрилансер) — услуги на бирже. ⚠️ В роутах — Service Provider.
    • Candidate (Кандидат) — пайплайн найма (без UI-роутов).

    Дизайн-система¶

    Токен (Design token)¶

    • EN: Design token · UA: Токен · ZH: 设计令牌
    • Именованная переменная дизайна (цвет, типографика, отступ, радиус, motion). Основа — AS Foundation Design Tokens v1.0. Шрифт — Rubik, базовый размер 14px, radius base 16px / small 8px.
    • См. также: Obsidian Vault/wiki/ИНТЕРФЕЙС/Design Tokens.md.

    CustomDataGrid¶

    • EN: CustomDataGrid · UA: CustomDataGrid · ZH: CustomDataGrid
    • Единый компонент таблиц, используемый во множестве представлений (заказы, склад, партии, поставщики, идеи, уведомления). Ширина колонок токенизируется по значению (col-width-100).
    • См. также: [[Фильтры данных]].

    Фильтры данных (Data filters)¶

    • EN: Data filters · UA: Фільтри даних · ZH: 数据筛选
    • Механика таблиц: выпадающий фильтр колонки заполняется реальными уникальными значениями, доступными пользователю (эндпоинт GET /api/v1/general/data_filters). Значения ограничены ролью, активными фильтрами и правами саб-юзера — см. «Видимость данных по роли» в PERMISSIONS_MATRIX.
    • Набор фильтруемых колонок задаётся по каждой таблице: products — 197 колонок (≈ поля Инвентаря, см. раздел «Inventory — поля таблицы»), orders — 22, boxes — 33, batches — 28, меньше — у ideas/tasks/requests и др.
    • Три системы фильтров: legacy filters, filters_v2 (JSON), customFilters.
    • Первоисточник: figma-mcp/docs/Data filters (01.04.26)*.md.
    • См. также: [[CustomDataGrid]].

    Inventory — поля таблицы (Amazon FBA)¶

    Справочник колонок таблицы Инвентарь (экран SCR-120). Источник: Google Sheet «Amazon Inventory Field Definitions» (1xhFaD86vBGzO6iB1LGn9onPuZqlQhjxf2DrzxWQ-81g). Названия колонок — это идентификаторы Amazon/UI и не переводятся (см. STYLE_GUIDE); определения даны на RU. Многие поля приходят из Amazon SP-API / SellerBoard.

    Идентификация товара¶

    Поле Определение
    ASIN Уникальный идентификатор товара на Amazon (Amazon Standard Identification Number) для поиска и управления позициями.
    Fnsku (FNSKU) Внутренний код Amazon (Fulfillment Network SKU) для отслеживания товаров на складах FBA.
    Баркод Штрихкод товара (UPC, EAN или внутренний FNSKU).
    HS code Международный код Гармонизированной системы для таможенной классификации.
    Маркетплейс Региональный маркетплейс Amazon (Amazon.com — США, Amazon.ca — Канада и т.д.).
    Магазин Название/идентификатор аккаунта Seller Central, управляющего продажами.
    Вариация Принадлежность товара к вариациям (цвет, размер, упаковка).
    Стратегия Данные бизнес-стратегии: ценообразование, маркетинг, логистика, управление запасами.
    Product Name Название товара на сайте (должно быть SEO-оптимизировано).
    Brand Бренд/торговая марка товара.
    Title Заголовок товара на странице листинга.
    Title Changed Изменялся ли заголовок относительно прошлых версий.
    Condition Состояние товара (New, Used, Refurbished и т.д.).
    Transparency Codes Участвует ли товар в программе Amazon Transparency (защита от подделок).
    Product Group Категория/подкатегория товара (Electronics, Clothing, Toys).
    Category / Subcategory Основная категория / уточнённая подкатегория товара.
    Category Link / Subcategory Link URL страницы категории/подкатегории на Amazon.
    Category Rank / Subcategory Rank Позиция товара внутри категории/подкатегории (меньше = выше продажи).
    Sales Rank BSR (Best Sellers Rank) — позиция в категории (меньше = популярнее).
    Теги Ключевые слова для внутреннего поиска/сегментации товаров.

    Запасы и склады (FBA / AS China / AS USA / AWD)¶

    Поле Определение
    Available Всего единиц, доступных к продаже на складе FBA.
    Reserved Quantity Единицы, зарезервированные под заказы/упаковку/подтверждение Amazon.
    Inbound Quantity Товары в пути на склад Amazon, ещё не обработаны.
    Inbound Working Товары физически на складе, но не полностью обработаны.
    Inbound Shipped Товары в пути от поставщика, ещё не прибыли.
    Inbound Received Приняты и зарегистрированы, но могут не отображаться как Available.
    Unfulfillable Quantity Единицы, непригодные к продаже (повреждение, брак, срок, возврат).
    Fba Inventory Level Health Status Индикатор дефицита/избытка/оптимального уровня запаса.
    Inbound To Awd Units Единицы, отправленные в систему Amazon Warehousing & Distribution (AWD).
    Available In Awd Units Запас в AWD-складах, готовый для FBA или прямой отправки клиенту.
    Outbound To Fba Units Товары, перемещаемые из AWD в основные склады FBA.
    In stock (AS CHINA) Количество товара на китайском складе.
    Prep limit (AS CHINA) Минимальный уровень запаса для китайского склада.
    In Transfer Единицы в процессе перемещения в резервный склад США (Prep center).
    In stock (AS USA) Всего единиц на складе США.
    Prep limit (AS USA) Минимальный рекомендуемый уровень запаса для склада США.
    Сумма стока Общее количество запаса по всем локациям (склады + заказы в пути).
    Стоимость стока Общая стоимость текущих остатков по закупочной/себестоимости.
    Order Общее количество, заказанное у поставщика.
    Срок изготовления, дн. Время производства/пополнения в днях до отправки на Amazon.
    Отложенный заказ Предзаказы, ещё не переданные в закупку, но запланированные.
    Рекомендация к дозакупке Автоматическая/ручная рекомендация к дозакупке.
    Минимальная партия Минимальное количество для заказа у поставщика (MOQ).
    Установить Дополнительно Служебное поле для ручных пометок/флагов доп. параметров.

    Прогноз запаса и оборачиваемость¶

    Поле Определение
    Days Of Supply Прогноз Amazon, на сколько дней хватит текущего запаса (по средней скорости продаж).
    Historical Days Of Supply На сколько дней в среднем хватало запаса за прошлые периоды (тренды).
    Short Term Historical Days Of Supply Тот же показатель за короткий период.
    Long Term Historical Days Of Supply Тот же показатель за длительный период.
    Last Updated Date For Historical Days Of Supply Дата последнего обновления исторических данных DoS.
    Weeks Of Cover T 30 / T 90 На сколько недель хватит запаса по продажам за 30/90 дней.
    Estimated Excess Quantity Расчётное количество лишнего товара по мнению Amazon.
    Sell Through Оборачиваемость (проданные единицы / средний запас за период).

    Возраст запаса и сборы за хранение¶

    Поле Определение
    Inv Age 0 To 30 / 31 To 60 / 61 To 90 Days Единицы на складе соответствующий период (в днях).
    Inv Age 0 To 90 Days Запас 0–90 дней без доп. платы за долгосрочное хранение.
    Inv Age 91 To 180 Days Запас 91–180 дней; начинается риск платы за долгосрочное хранение.
    Inv Age 181 To 270 / 181 To 330 / 271 To 365 / 331 To 365 Days Возрастные корзины запаса с растущими сборами.
    Inv Age 365 Plus Days Товары на складе более года — максимальные штрафные сборы.
    Pending Removal Quantity Единицы, запланированные к вывозу со склада FBA (возврат/утилизация).
    No Sale Last 6 Months Индикатор/кол-во товаров без продаж за 6 месяцев.
    Estimated Storage Cost Next Month Сумма списания за хранение в следующем месяце.
    Quantity To Be Charged Ais 181-210 … 365 Plus Days Кол-во единиц под плату за долгосрочное хранение (AIS) в диапазоне.
    Estimated Ais 181-210 … 365 Plus Days Сумма списания за хранение в соответствующем диапазоне.
    Fba Minimum Inventory Level Мин. количество для избежания stock-out.
    Exempted From Low Inventory Level Fee Освобождён ли товар от платы за низкий запас.
    Low Inventory Level Fee Applied In Current Week Применялась ли на этой неделе плата за низкий запас.
    Item Volume Физический объём единицы (для расчёта стоимости хранения).
    Volume Unit Measurement Единицы измерения объёма (см³, дюймы, фут³).
    Storage Type Категория товара в FBA (Standard, Oversize, Chilled).
    Storage Volume Общий объём хранения = Item Volume × количество.

    Продажи и отгрузки¶

    Поле Определение
    Orders / Total Orders Всего FBA-заказов по товару за период.
    Organic Orders FBA-заказы без платной рекламы (органика/SEO).
    Organic Units Единицы, проданные органическим трафиком.
    Units Всего проданных единиц (без деления на органику/рекламу).
    Returns Количество возвратов за период.
    Units Shipped T 7 / T 30 / T 60 / T 90 Единицы, отгруженные клиентам за 7/30/60/90 дней.
    Sales Shipped Last 7/30/60/90 Days Всего единиц, проданных за соответствующий период.
    Sales Сумма продаж за период ($).
    Date Дата записи (продажа, обновление, отчёт).
    Sales Per Units Средняя сумма продаж на единицу (Sales / Units).
    Units Per Orders Среднее число единиц в заказе.
    Fulfilled By Кто исполняет заказ: Amazon (FBA) или продавец (FBM).
    Sold By Информация о продавце; кто занимает Buy Box.
    Featuredoffer Price Цена в Buy Box, видимая покупателю.

    Клиентский опыт и отзывы¶

    Поле Определение
    Ncx Orders Заказы с жалобами/негативом покупателей.
    Ncx Rate Доля заказов с негативным опытом.
    Top Ncx Reason Наиболее частая причина недовольства (качество, задержки и т.д.).
    Pcx Health Показатель положительного клиентского опыта (Positive Customer Experience).

    Финансы (цены, комиссии, прибыль)¶

    Поле Определение
    Цена амазон Текущая цена продажи на Amazon.
    Your Price Текущая цена продавца (может отличаться при динамическом ценообразовании).
    Sales Price Итоговая цена для покупателя с учётом скидок/промо/купонов.
    Recommended Sales Price Цена, рекомендованная Amazon/аналитикой на основе конкуренции.
    Lowest Price New Plus Shipping Мин. цена нового товара среди конкурентов с доставкой.
    Lowest Price Used Мин. цена в категории Used.
    Прибыль Оценочная прибыль с учётом себестоимости, комиссий, рекламы, логистики.
    Net Profit Сумма после вычета всех расходов (себестоимость + комиссии).
    Margin Доля чистой прибыли от продаж (%).
    Roi Возврат на инвестиции (Return on Investment).
    All Fees Сумма всех комиссий (FBA, Referral, Storage и др.).
    FBA Комиссия Amazon за хранение/обработку/упаковку/доставку через FBA.
    Fba Fees Комиссия за обработку/упаковку/отправку (зависит от размера и веса).
    Ref Fees / Referral Fees Процентная комиссия Amazon с каждой продажи (обычно 8–15%).
    Cog Себестоимость: все затраты на производство/закупку/упаковку/доставку.

    Реклама¶

    Поле Определение
    Organic Sales Usd Продажи без рекламы, $.
    Adv Sales Usd Продажи от платной рекламы (sponsored), $.
    Organic Sales Percentage / Adv Sales Percentage Доля органических/рекламных продаж от объёма.
    Organic Units Percentage / Adv Units Percentage Доля единиц органика/реклама.
    Organic Sales Per Units / Organic Units Per Orders Средние органические показатели на единицу/заказ.
    Adv Orders Заказы после клика по рекламе.
    Adv Units Единицы, проданные через рекламные кампании.
    Adv Cost Сумма, потраченная на Amazon Sponsored Ads за период.
    Adv Conversion Percentage Доля кликов, приведших к заказу (заказы / клики).
    Tacos Total Advertising Cost of Sales: доля общей выручки на рекламу.
    Acos Percentage Отношение рекламных затрат к продажам от рекламы.
    Adv Impressions Число показов рекламы.
    Adv Clicks Число кликов по рекламе.
    Adv Cpc Средняя цена за клик.
    Adv Ctr Доля кликнувших после показа (клики / показы).
    Adv Cost Per Units Средние рекламные затраты на проданную единицу.
    Adv Sales Per Units Средняя выручка от рекламы на единицу.

    Рекомендации Amazon¶

    Поле Определение
