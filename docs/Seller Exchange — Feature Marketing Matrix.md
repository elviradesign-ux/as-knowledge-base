Version: 1.0
Purpose: Marketing planning for short interface videos (15–45 sec)

# TIER 1 — Hero Features

Это ролики, которые должны продавать платформу.

| Feature | Business Problem | Value Proposition | Hero Moment | Duration | Priority |
|----------|------------------|-------------------|-------------|----------|----------|
| Inventory Management | Потеря контроля над товарами | Вся информация по товарам в одном месте | Фильтр → таблица перестраивается → найден нужный товар | 20–30s | ⭐⭐⭐⭐⭐ |
| Product Card | Разрозненная информация о товаре | Полная карточка жизненного цикла товара | Открытие карточки → фотографии → метрики → поставщики → история | 30–40s | ⭐⭐⭐⭐⭐ |
| Supplier Search | Долгий поиск поставщиков | Быстро найти подходящего производителя | Поиск → фильтры → найден поставщик | 20–30s | ⭐⭐⭐⭐ |
| Warehouse Management | Сложное управление складом | Полный контроль складской логистики | Коробки → партии → статусы → готово | 30s | ⭐⭐⭐⭐⭐ |
| Order Management | Потеря контроля заказов | Управление заказами в одном месте | Новый заказ → изменение статуса → уведомление | 20–30s | ⭐⭐⭐⭐ |
| Product Launch | Запуск товара занимает недели | Пошаговый процесс запуска | Последовательно проходят этапы Launch Workflow | 30–45s | ⭐⭐⭐⭐ |
| Product Exchange | Поиск новых продуктов | Внутренняя биржа товарных идей | Поиск → открытие предложения → покупка | 20–30s | ⭐⭐⭐⭐ |
| Service Provider Marketplace | Поиск исполнителей | Найти специалиста без выхода из платформы | Создание заявки → отклики → принятие результата | 30–40s | ⭐⭐⭐⭐⭐ |
