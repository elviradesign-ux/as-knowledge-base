# Seller Exchange — База знаний

> Внутренняя wiki по продукту Seller Exchange (внутр. кодовое имя **AmazonService / AS**).

Эта база знаний описывает сущности, роли, экраны и сценарии платформы для
продавцов на Amazon. Она строится поверх продуктовой wiki и макетов Figma —
подробнее в [Manifesto](MANIFESTO.md) и [Information Architecture](INFORMATION_ARCHITECTURE.md).

- [Glossary](GLOSSARY.md) — единый словарь терминов
