# С чего начать

Эта страница — маршрут для нового пользователя Seller Exchange. Пройдите шаги по
порядку.

## Первые шаги

1. **[Первый вход](046-first-login.md)** — войти или зарегистрироваться.
2. **[Подключить магазин Amazon](047-connect-amazon-store.md)** — чтобы данные о
   товарах и продажах начали синхронизироваться.
3. **[Настроить команду](048-set-up-team.md)** — добавить участников и права
   (если работаете не в одиночку).
4. **[Создать первый товар](049-create-first-product.md)** — завести позицию в
   инвентаре.
5. **[Создать первый заказ](050-create-first-order.md)** — оформить закупку.
