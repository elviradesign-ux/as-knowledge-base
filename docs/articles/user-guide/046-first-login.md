# Первый вход

## Кратко

Чтобы начать работу, войдите в аккаунт или зарегистрируйтесь. После входа вы
попадаете на свой дашборд — вид зависит от [роли](../foundations/008-role.md).

## Шаги

1. Откройте экран входа ([SCR-001](../../SCREEN_CATALOG.md)).
2. Введите логин и пароль **или** зарегистрируйтесь
   ([SCR-002](../../SCREEN_CATALOG.md)).
3. При необходимости переключите язык в хедере (EN / RU / ZH / UA).
4. Войдите — откроется дашборд.

## Результат

- Вы авторизованы; доступен раздел по вашей роли.

## Частые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| Не входит | Неверные данные | Проверить логин/пароль; восстановить доступ |
| Пустой дашборд | Не подключён магазин | [Подключить магазин](047-connect-amazon-store.md) |
