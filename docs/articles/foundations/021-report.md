# Что такое отчёт

**Отчёт** (Report) — аналитический срез данных: по товарам, инвентарю, продажам,
финансам или рекламе. Отчёты помогают принимать решения на основе цифр.

## Кратко

Отчёт — это готовый взгляд на данные под конкретную задачу (например, по
листингам, возвратам, продажам или PPC). Отчёты строятся над товарами, инвентарём
и магазинами.

## Что это такое

Отчёт — производный от данных объект: он не хранит новые факты, а показывает срез
уже существующих. На платформе есть несколько типов отчётов (по инвентарю,
заказам, рекламе, финансам и др.).

## Зачем это нужно

- Даёт основу для решений по дозакупке, ценообразованию и рекламе.
- Сводит данные из разных областей в удобный вид.
- Отчёты по листингам и парсингу помогают следить за состоянием товаров.

## Основные атрибуты

- **Тип отчёта** — по какой области построен (инвентарь, продажи, реклама и т.д.).
- **Источник** — товары / инвентарь / магазин, над которыми построен срез.

## Жизненный цикл и статусы

Отдельного набора статус-кодов у отчёта в базе знаний нет — это срез данных.

> Полный перечень типов отчётов (ORDERS, INVENTORY, RETURNS, BUSINESS_REPORTS,
> INCOME, TRANSACTIONS, VOICE, FBA_INVENTORY и др.) есть в инженерной доке
> `docs/Data filters*.md`. Какие из них описывать как отдельные продуктовые
> статьи — **уточняется (DM19)**.

## Связи с другими сущностями

- Отчёт **строится из** товара и инвентаря.
- Отчёты по рекламе связаны с кампаниями; отчёты парсинга — с магазином.

Точные связи — в [Entity Relationships](../../ENTITY_RELATIONSHIPS.md).

## Кто работает с этой сущностью

- **Client** — отчёты по своим товарам/магазинам.
- **Supervisor / Admin** — аналитика в рамках своих прав.

Доступ — см. [Permissions Matrix](../../PERMISSIONS_MATRIX.md).
