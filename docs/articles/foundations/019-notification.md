# Что такое уведомление

**Уведомление** (Notification) — оповещение пользователя о событиях на платформе:
по заказам, коробкам, тарифам и заявкам. Уведомления помогают вовремя реагировать
на то, что требует внимания.

## Кратко

Уведомление сообщает, что произошло что-то важное — например, изменился заказ или
поступила коробка. Уведомления сгруппированы по темам (вкладкам), чтобы их было
проще разбирать.

## Что это такое

Уведомление ссылается на объект, о котором сообщает (заказ, коробка, тариф,
заявка), и показывается в разделе «Уведомления». У клиента уведомления разделены
на несколько вкладок по темам.

## Зачем это нужно

- Держит пользователя в курсе значимых событий.
- Позволяет быстро перейти к объекту, требующему действия.
- Разделение по темам упрощает работу с большим потоком событий.

## Основные атрибуты

- **Тема** — по заказам / коробкам / тарифам коробок / заявкам / общие.
- **Объект** — на какой заказ/коробку/тариф/заявку ссылается уведомление.

## Жизненный цикл и статусы

Отдельного набора статус-кодов у уведомления в базе знаний нет. Уведомления
сгруппированы по вкладкам (у клиента — пять: по заказам, по коробкам, по тарифам
коробок, по заявкам, общие).

## Связи с другими сущностями

- Уведомление **ссылается** на заказ, коробку, тариф.
- Также уведомления касаются заявок (Service Request).

Точные связи — в [Entity Relationships](../../ENTITY_RELATIONSHIPS.md).

## Кто работает с этой сущностью

Уведомления получают **Client, Buyer, Storekeeper, Freelancer, Admin**. Каждый
видит уведомления по своим объектам — см.
[Permissions Matrix](../../PERMISSIONS_MATRIX.md).
