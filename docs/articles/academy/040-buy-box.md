# Что такое Buy Box

**Buy Box** — блок покупки на карточке товара Amazon (кнопки «Add to Cart» /
«Buy Now»), из которого совершается большинство заказов. Если несколько продавцов
продают один товар, за Buy Box идёт конкуренция.

## Кратко

Buy Box — «место», откуда покупатель чаще всего покупает. Продавец, занявший Buy
Box, получает большую часть заказов по этому товару.

## Что это такое

На платформе Buy Box отражён через поля товара: цену в Buy Box и продавца,
который его занимает. Полные определения — в
[справочнике полей](../../GLOSSARY.md).

- **Featuredoffer Price** — цена, видимая покупателю в Buy Box.
- **Sold By** — какой продавец занимает Buy Box (если продавцов несколько).

## Зачем это нужно

- Buy Box напрямую влияет на объём продаж товара.
- Позволяет понять, выигрываете ли вы предложение по товару.
- Помогает оценивать ценовую конкуренцию.

## Где это видно в интерфейсе

Цена Buy Box и продавец — поля товара в
[инвентаре](../foundations/002-inventory.md)
