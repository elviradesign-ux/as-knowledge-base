# Glossary — единый словарь терминов

> Единственный источник определений Seller Exchange (внутр. **AmazonService /
> AS**). Термины из статей ссылаются сюда (см. [STYLE_GUIDE](STYLE_GUIDE.md)).
> Правило: один термин — одна запись.
>
> Первоисточники: `Obsidian Vault/wiki/*`, `platform-routes.md`.

## Формат записи

```
### Термин
- **EN:** … · **UA:** … · **ZH:** …
- Определение: одно-два предложения.
- См. также: [[связанный-термин]], экран/сценарий.
```

## Платформа и сущности

### Seller Exchange / AmazonService (AS)
- **EN:** Seller Exchange · **UA:** Seller Exchange · **ZH:** Seller Exchange
- Мульти-ролевая SaaS-платформа для продавцов Amazon: заменяет 5–10 отдельных
  инструментов (Helium10, JungleScout, Keepa, SellerApp и др.) единым рабочим
  пространством — товары, заказы, инвентарь, склады, аналитика, командная работа.
- Внутреннее кодовое имя — **AmazonService / AS**.

### Карточка продукта (Product Card / ASIN card)
- **EN:** Product card · **UA:** Картка товару · **ZH:** 商品卡片
- Единица товара с данными ASIN, вариантами и статусом готовности. Проходит
  пайплайн ресёрч → проверка → публикация на бирже.
- См. также: [[ASIN]], [[Биржа товаров]], [[Готовые к проверке]].

### ASIN
- **EN:** ASIN · **UA:** ASIN · **ZH:** ASIN
- Amazon Standard Identification Number — идентификатор товара на Amazon.
  Проверяется через ASIN-чекер (Supervisor Settings).

### Заказ (Order)
- **EN:** Order · **UA:** Замовлення · **ZH:** 订单
- Запрос клиента на закупку товара; проходит жизненный цикл от Pending до
  Order complete. Обрабатывается Buyer, комплектуется Storekeeper.
- См. также: [[Статус заказа]], [[Коробка]], [[Партия]].

### Статус заказа (Order status)
- **EN:** Order status · **UA:** Статус замовлення · **ZH:** 订单状态
- Этап жизненного цикла заказа. Канонические коды (FORMED=0 … SHIPPED=50) —
  в [ENTITY_STATES](ENTITY_STATES.md) → «Статусы заказа». Вкладки Buyer:
  not-paid, ready-for-payment, partially-paid, need-track-number, inbound,
  confirmation-required, closed-and-canceled.
- См. также: [[Заказ]], [ENTITY_STATES](ENTITY_STATES.md),
  [WORKFLOW_CATALOG](WORKFLOW_CATALOG.md).

### Коробка (Box)
- **EN:** Box · **UA:** Коробка · **ZH:** 箱
- Физическая единица хранения/отправки товара на складе. Коробки создаются,
  редактируются, группируются, объединяются, перераспределяются и перемещаются
  в партии.
- См. также: [[Партия]], [[Склад]].

### Партия (Batch)
- **EN:** Batch · **UA:** Партія · **ZH:** 批次
- Группа коробок, отправляемых вместе. Статусы: ожидающие отправки, отправленные,
  архив. Имеет Prep ID.
- См. также: [[Коробка]], [[Склад]].

### Тариф (Tariff)
- **EN:** Tariff · **UA:** Тариф · **ZH:** 资费
- Стоимость логистики/хранения по региону. Настраивается в Управлении складом
  (`WarehouseManagementView`), уточняется модалками `TariffModal`,
  `LogisticsTariffModal`.

### Поставщик (Supplier)
- **EN:** Supplier · **UA:** Постачальник · **ZH:** 供应商
- Источник товара. Находится Buyer, верифицируется Supervisor. Данные: цена,
  доставка, HS-код, материал, назначение.
- См. также: [[Заказ]], [[Карточка продукта]].

### Идея / Запуск товара (Idea / Product Launch)
- **EN:** Idea / Product launch · **UA:** Ідея / Запуск товару · **ZH:** 选品/上新
- Кандидат на запуск: проходит вкладки new-ideas → on-checking → supplier-search
  → create-card → adding-asin → realized/rejected. Управляется через `IdeaModal`.

### Ниша (Niche)
- **EN:** Niche · **UA:** Ніша · **ZH:** 细分市场
- Раздел биржи товаров с нишевыми предложениями (`NicheView`).

### Магазин (Store / Shop)
- **EN:** Store · **UA:** Магазин · **ZH:** 店铺
- Подключённый аккаунт Amazon с авто-обновлением данных. Раздел `/shops`.

## Роли и доступ

### Роль (Role)
- **EN:** Role · **UA:** Роль · **ZH:** 角色
- Набор прав RBAC. 8 продуктовых ролей + служебные (Moderator, Guest).
- См. также: [PERMISSIONS_MATRIX](PERMISSIONS_MATRIX.md).

### Саб-пользователь (Sub-user)
- **EN:** Sub-user · **UA:** Суб-користувач · **ZH:** 子用户
- Дополнительный пользователь под основным аккаунтом с урезанными правами
  (`SubUsersView`, `LinkSubUserModal`).

### Пресет разрешений (Permissions preset)
- **EN:** Permissions preset · **UA:** Пресет прав · **ZH:** 权限预设
- Именованный набор доступов, уточняющий права внутри роли. Настраивается через
  `PermissionsModal`, `SinglePermissionModal`, `GroupPermissionModal`.
- См. также: [[Роль]], [[Саб-пользователь]].

## Роли (короткие определения)

- **Admin (Админ)** — полный доступ, настройки, права, парсинг.
- **Supervisor (Супервайзер)** — проверка карточек, верификация поставщиков, ASIN-чекер.
- **Buyer (Байер)** — сорсинг, поставщики, обработка заказов.
- **Client (Клиент)** — конечный клиент: заказы, инвентарь, склад, аналитика.
- **Researcher (Ресечер)** — ресёрч, создание карточек.
- **Storekeeper (Сторкипер)** — склад, коробки, партии, задачи.
- **Freelancer (Фрилансер)** — услуги на бирже. ⚠️ В роутах — **Service Provider**.
- **Candidate (Кандидат)** — пайплайн найма (без UI-роутов).

## Дизайн-система

### Токен (Design token)
- **EN:** Design token · **UA:** Токен · **ZH:** 设计令牌
- Именованная переменная дизайна (цвет, типографика, отступ, радиус, motion).
  Основа — AS Foundation Design Tokens v1.0. Шрифт — **Rubik**, базовый размер
  14px, radius base 16px / small 8px.
- См. также: `Obsidian Vault/wiki/ИНТЕРФЕЙС/Design Tokens.md`.

### CustomDataGrid
- **EN:** CustomDataGrid · **UA:** CustomDataGrid · **ZH:** CustomDataGrid
- Единый компонент таблиц, используемый во множестве представлений (заказы,
  склад, партии, поставщики, идеи, уведомления). Ширина колонок токенизируется
  по значению (`col-width-100`).
- См. также: [[Фильтры данных]].

### Фильтры данных (Data filters)
- **EN:** Data filters · **UA:** Фільтри даних · **ZH:** 数据筛选
- Механика таблиц: выпадающий фильтр колонки заполняется реальными уникальными
  значениями, доступными пользователю (эндпоинт
  `GET /api/v1/general/data_filters`). Значения ограничены ролью, активными
  фильтрами и правами саб-юзера — см. «Видимость данных по роли» в
  [PERMISSIONS_MATRIX](PERMISSIONS_MATRIX.md).
- Набор фильтруемых колонок задаётся по каждой таблице: `products` — 197 колонок
  (≈ поля Инвентаря, см. раздел «Inventory — поля таблицы»), `orders` — 22,
  `boxes` — 33, `batches` — 28, меньше — у `ideas`/`tasks`/`requests` и др.
- Три системы фильтров: legacy `filters`, `filters_v2` (JSON), `customFilters`.
- Первоисточник: `figma-mcp/docs/Data filters (01.04.26)*.md`.
- См. также: [[CustomDataGrid]].

| Recommended Ship In Quantity | Сколько единиц рекомендуется отправить на склад. |
| Recommended Ship In Date | Дата, к которой рекомендуется пополнить запас. |
| Deprecated Healthy Inventory Level | Устаревшая метрика оптимального запаса (заменена новыми). |

## Правила ведения

- Новый термин добавляется до первого использования в статьях.
- Синонимы указываются в теле термина, не отдельной записью.
- Переводы согласуются с [LOCALIZATION_GUIDE](LOCALIZATION_GUIDE.md).
- Точные формулировки строк UI берём из `figma-mcp/localizations/*.tokens.json`
  (ключи `label_*`, `actions_*`, `info_*`) — не сочиняем на слух.
- Коды и статусы сущностей (роли, товар, заказ, коробка, партия, задачи) —
  в [ENTITY_STATES](ENTITY_STATES.md); в глоссарии на них ссылаемся, не дублируем.
- Термин без утверждённого перевода: `(TODO: <lang>)`.
